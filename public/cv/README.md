# CV Directory

Place the tailored resume PDFs in this folder with the following filenames:
- `backend.pdf` - Backend Developer resume
- `fullstack.pdf` - Full-Stack Developer resume
- `dba.pdf` - Database Administrator resume
- `infra.pdf` - Infrastructure / IT Support resume
- `general.pdf` - General / Complete CV (fallback for any missing role CV and default for 'all')

If a specific role CV is not yet uploaded, the application automatically falls back to `general.pdf`.
